A sophisticated network security monitoring tool that captures live network traffic, detects anomalies using AI-powered analysis, and displays threats on a real-time dashboard.

---

## 🎯 Project Overview

Network Threat Visualizer combines traditional signature-based detection with AI-powered behavioral analysis to identify network security threats in real-time.

### Detectable Threats
- 🔍 **Port Scanning** - Reconnaissance attacks
- 💥 **DDoS Attacks** - Traffic floods  
- 📤 **Data Exfiltration** - Unauthorized transfers
- 🔐 **Brute Force** - Authentication attacks
- 🤖 **AI-Enhanced Detection** - Behavioral analysis
